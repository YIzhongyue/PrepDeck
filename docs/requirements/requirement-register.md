# Requirement register

[Documentation index](../README.md)

This register preserves every originally defined FR identifier, including
FR-2.3.1 and FR-7.0. IDs are never reused for unrelated work. M/S/C means
Must/Should/Could, not completion. Follow each owning document for evidence,
limitations and issue links; implemented does not claim exhaustive QA.

The old FR-3.9 reference was a typo, not a defined requirement; FR-8.3 owns the
review-only rule. FR-1.1/FR-1.6 supersede Access-only authentication, FR-1.4
corrects revocation consistency, and FR-13.1 supersedes the nested URL design.
No valid FR has been silently dropped. Newer issue-based behaviors remain traced
by their issue links rather than inventing new FR numbering during a docs refactor.
